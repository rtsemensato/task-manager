# web

Frontend Angular do Task Manager. Ver o [README na raiz do repositório](../README.md)
pra visão geral do projeto (backend incluso) e instruções completas de setup.

## Rodando só este pacote

```bash
npm install
npm start
```

Abre em [http://localhost:4200](http://localhost:4200). Espera a API rodando em
`http://localhost:8000` (ver `../api`).
